# WoW Forever Fury Warrior Gameplay Sim

A browser sim for practising the level 60 Fury Warrior rotation in World of Warcraft: Forever. You press the abilities; the sim auto-attacks a raid boss dummy, tracks rage and cooldowns, and shows a damage breakdown when the dummy dies.

**Play it:** https://wowf-gameplay.github.io/warrior-gameplay-sim/

## Features

- Bloodthirst, Whirlwind, Heroic Strike, Execute, Overpower, Hamstring, Berserker Rage, Bloodrage, Death Wish, Recklessness and Mighty Rage Potion
- Forever's normalized rage, stances with automatic switching, Flurry, Deep Wounds and weapon procs
- Toggles for raid buffs, consumables and boss debuffs
- Gear and talent tabs, plus a Stats tab for entering your own character stats
- Rebindable keys (with Shift/Ctrl), adjustable dummy health, and an end-of-fight overview

## Setup

The default gear, enchants and 18/31/2 talent build follow the [MythicSim](https://mythicsim.com/wow-forever/warrior) DPS Warrior preset. Talent and ability values come from the Forever beta and may change as the beta does.

## Running locally

It is a single file with no build step: open `index.html` in a browser. Ability icons load from Wowhead's image server, so they need an internet connection.
